# Security Policy

DZ_Shutdown is currently undergoing security hardening.

The historical implementation includes remote administrative functionality and should not be exposed to untrusted networks.

## Current publication policy

The legacy source is intentionally withheld from this public repository until authentication, authorization, network restrictions, and command-execution controls are added.

## Reporting

If you identify a security issue in a future published version, avoid posting credentials, private host information, access tokens, or sensitive screenshots in a public issue.
